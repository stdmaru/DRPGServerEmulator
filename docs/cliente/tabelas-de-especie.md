# Tabelas por espécie (cliente) ✅

Tabelas fixas no código da v322 usadas para desenhar digimons fora do mapa. Extraídas do binário (`0x00b23d20` e `0x00b46120`); a espécie é o `leaderSpecies` do slot do `0x12`.

## Espécie → id do sprite (`0x00b23d20`)
O sprite é `Sprite\%03d_1.ani` com o id resultante. Espécies fora da tabela usam o próprio número. Casos especiais em `0x00b46120`: id 610 → `Sprite\tamer_09`; 817 com `+0x80 == 2` → `Sprite\817_2.ani`; arquivo inexistente → `Sprite\065_1.ani`.

## Deslocamento na seleção de personagens (`0x00b46120`)
O digimon do slot é desenhado com o canto superior esquerdo do quadro em (xBotão + dx, yBotão + dy), onde (xBotão, yBotão) é a posição do botão do slot ([cenas](cenas.md#cscenecharsel-seleção-de-personagens-)). **Padrão: (−40, −14).** Exceções, pela espécie (não pelo id do sprite):

- Espécies 638, 639, 641–644, 647, 648, 650, 653: centradas em (135, 140) **relativos ao botão**: `(xBotão + 135 − w/2, yBotão + 140 − h/2)`, com w, h do quadro atual. ❓ Confirmar se é relativo ao botão ou absoluto.
- Espécie 645: centrada em (135, 110), mesma regra.
